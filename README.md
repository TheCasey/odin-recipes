# Odin Recipes

An HTML fundamentals exercise from The Odin Project. The index links to three recipe pages with ingredients, instructions, and images.

## View locally

Open `index.html` in a browser. There is no package installation, build step, backend, or automated test suite.

## Learning focus

Relative links, document structure, lists, and images. Useful manual checks include following every recipe link, confirming images load, checking heading order, and navigating with a keyboard.

This is a learning exercise rather than a featured application. More substantial projects are listed on [the profile](https://github.com/TheCasey).
